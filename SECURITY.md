# Security

Loot holds store credentials and mounts webhook endpoints, so security reports
are taken seriously and are very welcome.

## Reporting a vulnerability

Please **do not open a public issue**. Report it privately instead:

1. Go to the [Security tab](https://github.com/NickHirras/loot/security) of
   this repository.
2. Choose **Report a vulnerability** and describe what you found.

Useful things to include: the version or commit, how Loot is deployed (binary,
Docker, behind a proxy), the steps to reproduce, and what an attacker gains.

This is a one-person project. You should hear back within a week, and a fix
for anything serious ships as soon as it is ready, with credit to you in the
release notes unless you would rather not be named.

## Supported versions

Only the latest release and `main` (the `edge` image) receive fixes.
